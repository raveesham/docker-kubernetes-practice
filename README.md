# Docker & Kubernetes Practice

A hands-on DevOps practice repository covering **Docker, Docker Compose, Docker Hub, Kubernetes, Git, GitHub, and Jenkins CI/CD**.

This project demonstrates containerization, storage, networking, resource management, troubleshooting, Kubernetes workloads, image management, and automated application testing with Jenkins.
